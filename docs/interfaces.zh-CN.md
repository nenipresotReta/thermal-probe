# 硬件接口

[English](interfaces.md) | [简体中文](interfaces.zh-CN.md)

本表定义当前固件的接口。GPIO 数字是芯片 GPIO 编号，不是连接器脚位序号。上电前核对自己的原理图；不使用接线图片。

## 支持目标

已测试目标为 16 MB Flash 的 ESP32-S3 显示板，170 × 320 ST7789、8 位 8080 总线。板目标为 `tdisplay_s3/esp32s3/procpu`，PSRAM 关闭。产品名称相同不能证明电气兼容。

启动时 GPIO15 输出高电平，作为已测试板的电源使能。移植到其他板前须核对该脚和屏幕总线。`headless.conf` 关闭同一板的 LCD 和 GPIO14 界面；目前没有通用 ESP32 板配置。

## MAX31865 数字接口

方向以 ESP32 为参照。

| ESP32 信号 | 方向 | 模块信号 | 要求 |
|---|---|---|---|
| 3V3 | 电源 | 模块规定的电源输入 | 必须能使用可用的 3.3 V 电源和 SPI 逻辑 |
| GND | 参考 | GND | 共地 |
| GPIO10 | 输出 | CS | 低有效片选 |
| GPIO11 | 输出 | SDI / MOSI | 进入 MAX31865 的数据 |
| GPIO12 | 输出 | CLK / SCK | SPI 时钟，模式 1 |
| GPIO13 | 输入 | SDO / MISO | MAX31865 输出，不得超过 ESP32 逻辑电压 |
| 不接 | — | RDY | 固件轮询 |

**不同模块的 VIN 和 3V3 不能直接互换。** 已测试模块从 VIN 输入 3.3 V，模块的 3V3 稳压输出悬空。其他模块应核对输入范围、稳压压差及 3V3 是否允许直接供电，不能只凭标签把两个电源脚都接上。本设计不用开发板 +5 V；电池供电不代表 +5 V 会输出。

## 三线 PT100

固件假设 PT100 在 0°C 为 100 Ω、参考电阻 430 Ω、三线补偿、50 Hz 抑制。PT1000、其他参考电阻、两线／四线、60 Hz 需要修改源码；`config/device.json` 只配置 Wi-Fi。

断开探头后，按规格或电阻测量找出同端两根线：它们之间约为导线电阻，各自到另一根线约为探头电阻。不要只看线色。

| 探头线 | 模块端子 |
|---|---|
| 同端第一根 | F+ / FORCE+ |
| 同端第二根 | RTD+ / RTDIN+ |
| 另一端单线 | RTD− / RTDIN− |
| 无额外探头线 | F− / FORCE−，在模块上桥接 RTD− |

| 跳线 | 三线状态 |
|---|---|
| `2/3 Wire` | 闭合，连接 F− 和 RTD− |
| `2 Wire` | 断开，不在模块上短接 F+ 和 RTD+ |
| 三焊盘 `24 / 3` | 中间接 `3`，中间与 `24` 断开 |

如果实际模块出厂有中间到 `24` 的铜桥，先断开它，再连接中间到 `3`。断开全部电源和探头后用万用表确认；照片不能证明导通。没有确认存在连接就不要切。三个焊盘不能全部连通。接入前先把探头从原变送器断开。

## 显示和控制

| 信号 | GPIO |
|---|---|
| LCD D0、D1、D2、D3 | 39、40、41、42 |
| LCD D4、D5、D6、D7 | 45、46、47、48 |
| LCD reset、CS、DC | 5、6、7 |
| LCD WR、RD | 8、9 |
| 背光 | 38 |
| 用户按钮 | 14 |
| 板载电源使能 | 15 |

用户按钮只控制本地显示，不能代替 BOOT／RESET。下载和日志使用原生 USB；打开串口可能重置板子，检查连续运行时间时先关掉串口工具。

## 配置位置

| 配置 | 位置 |
|---|---|
| Wi-Fi | 本地 `config/device.json` |
| 传感器脚位、参考电阻、PT100 曲线、抑制模式、100 ms 循环 | `src/main.c` |
| 滤波窗口 | `src/filter.h`、`src/filter.c` |
| LCD 开关 | Kconfig 的 `CONFIG_THERMAL_DISPLAY`；`headless.conf` 关闭 |
| LCD 驱动／脚位 | `src/tdisplay_lcd.c` |
| 显示／按钮 | `src/display.c` |
| Flash 布局／USB 控制台 | `boards/lilygo/tdisplay_s3/` |

修改板或传感器参数后重新构建并验证实物。数值换算范围不代表探头、电缆、外壳允许的温度范围。
